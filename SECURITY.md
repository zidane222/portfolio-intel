# Security policy

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository.
Please don't open a public issue. You'll get a reply within 3 business days.

In scope: the Portfolio Intel web app, the `portfolio-intel-api` Worker and its services.
Please don't test against other users' data, run denial-of-service tests, or use social engineering.

How data is protected is described in `docs/ARCHITECTURE.md` and `docs/compliance/CONTROLS.md`.
