# Compliance readiness

Portfolio Intel is preparing for the frameworks below. This is **readiness**, not certification:
a SOC 2 or SOC for Cybersecurity report can only be issued by a licensed CPA firm after an audit.

| Framework | Applies | Status |
|---|---|---|
| SOC 2 Type I (Security, Availability, Confidentiality, Privacy) | Yes | Readiness in progress, see CONTROLS.md |
| SOC 2 Type II | Yes, after Type I | Needs 3 to 12 months of evidence, collected in EVIDENCE.md |
| SOC 3 | Yes, public summary of SOC 2 | Follows SOC 2 |
| SOC for Cybersecurity | Yes | Same controls, entity-wide description |
| NIST CSF 2.0 | Yes, as the internal framework | Mapped in CONTROLS.md |
| GLBA Safeguards Rule | When other users connect financial accounts (Plaid production) | Mapped, owner designation done |
| Plaid production security review | Before Plaid production | Mapped |
| OWASP ASVS L2 | Yes | appsec agent reviews each PR |
| CCPA basics | Voluntary at current size | Privacy policy and delete-my-data in place |
| SEC investment advice guardrail | Yes | No personalized advice, simulated strategies only |
| SOC 1 | No | No customer financial reporting |
| SOC for Supply Chain | No | No physical product |
| PCI DSS | No | No card data handled |

Files: `CONTROLS.md` (control map), `RISK_REGISTER.md`, `EVIDENCE.md`, `ROADMAP.md`, `policies/`.
