# Competitive intel report, November 2026

Date: 2026-11-07. Author: competitive-intel agent. First report, so this is a baseline.
Status: research only. Every recommendation below is a proposal. The architect turns accepted ones into a plan and the owner approves before anything is built.

## Summary

The congressional trade market has split into three layers. Free browsers (Capitol Trades) show filings. Data and quant products (Quiver Quantitative, Unusual Whales) sell alerts, backtests and APIs, and both now ship MCP or agent access. Copy-trading apps (Autopilot) turn filings into brokerage orders. Everyone discloses the same limit: filings arrive up to 45 days late and only as dollar ranges, so none can be real time [S1, S21]. Our app already shows filing lag, "Filed late" flags, a "Best to copy" tab, a simulated copy test, labeled news reads, savings rates, dividends, risk, private-market filings, and weekly insights. Our edge is the checked-answer pipeline (fact checker plus rule validator plus meta supervisor), device-encrypted holdings, and no trading. The main gaps are alerts that need no setup (ours need a manual ntfy topic), a public methodology and change log, a portfolio-level AI digest (Robinhood Gold and Simply Wall St both have one), and benchmarked, lag-aware copy results (Public backtests against the S&P 500; we found no benchmark in our copy test). Seven recommendations follow. Pricing data is second-hand in several cases because official pricing pages were not reachable this run; those rows are marked.

## Ranked recommendations

Ranked by impact over effort. All are proposals.

### R1. Public methodology and change log page for insights and AI features
- Owner: `compliance`
- Impact: medium. Effort: S.
- Evidence: Public keeps a dated change log for Generated Assets, with entries from Nov 20, 2025 to Mar 27, 2026 [S14], and labels output "Generated with AI" with a backtest caveat [S12]. Forge states its index method, rebalance rule and data limits on the page [S17]. Fiscal.ai's reviewer says the AI citation method is unclear [S10]. We already carry `method_version`, `code_version`, `params` and a label in `insights.json`, and fixed validator rules in `docs/ARCHITECTURE.md`.
- User problem: a user who sees a simulated result or a news read cannot easily learn how it was made, what it excludes, or when the method changed.
- Risks: compliance wording must not read as a performance claim or advice (V4, V13, V22 apply). Low cost. No data licensing issue. Keep prompt text out of the page if it would help prompt injection.

### R2. Review queue for unreadable and scanned filings
- Owner: `meta-supervisor`
- Impact: medium. Effort: S.
- Evidence: Capitol Trades says its data mixes automated and manual collection and that analysts check published data [S6]. Our meta supervisor notes year-long known gaps (scanned filings, dates after filing) as OK lines and treats a member missing because a filing is unreadable as WARN (`docs/ARCHITECTURE.md`, Meta supervisor section). Kiplinger notes the ranges and delay problem already limit trust in these feeds [S21].
- User problem: members whose scanned filings we cannot read look quiet in our data. That can read as "no trades" when the truth is "not parsed".
- What to add: a check that lists unreadable filings by member and age, escalates when one stays unresolved past a set number of days, and gives the owner a short manual-entry list. Also show "filing not readable" on that member's page.
- Risks: manual entry needs a review rule so a human error is not published as fact. No new data source.

### R3. Alerts that need no setup
- Owner: `ux-discovery`
- Impact: high. Effort: M.
- Evidence: Unusual Whales and Quiver list alerts as a paid feature [S1, S2]. Quiver announced app stock alerts as "coming" in Aug 2025 [S3]. Capitol Trades alerts are "Limited" [S1]. Disclosed Capitol advertises webhooks [S22]. Ours need the user to copy an ntfy topic and fill rule fields by hand (`js/14-alerts.js`).
- User problem: most users will not set up a third-party topic, so the most useful thing we know (a new filing in a stock they own) reaches few of them.
- What discovery should answer: Web Push or email, what the message may contain, and how the rule runs without sending the user's holdings to a server in plain text (house rule). Research first, no build.
- Risks: privacy (the server must not learn holdings, so matching on device or on public tickers only), notification wording must not imply a signal to trade, cost of push delivery, ntfy topics are guessable if short (already lengthened).

### R4. Plain explainer for private-market filings
- Owner: `frontend`
- Impact: low to medium. Effort: S.
- Evidence: Wefunder explains the Reg CF limit for non-accredited investors in plain rules [S20]. Robinhood describes its private fund as "speculative and involves a high degree of risk" and lists illiquidity and valuation uncertainty [S16]. Forge warns its prices may rest on very few trades [S17]. Our view lists Form D and Form C filings only (`docs/ARCHITECTURE.md`, pi-private).
- User problem: a filing list can look like an offer or a signal. Users need to know what a Form D or Form C is, what it does not show (no valuation, no returns), and that these deals are illiquid.
- Scope: static text panel with the rules as general facts. No personal limit calculator, because it would need income and net worth.
- Risks: wording must stay educational (not advice). Keep us on filings, not valuations, which also avoids Forge-style data licensing.

### R5. Benchmarked, lag-aware copy results
- Owner: `data-science`
- Impact: medium. Effort: M.
- Evidence: Public backtests each generated index against the S&P 500 and labels it hypothetical [S12, S13]. Autopilot cites a company claim of about 150% for Pelosi's tracked portfolio since 2021 [S7], and a competitor-written page says Quiver shows member returns as raw figures, not benchmarked [S4, vendor-written]. Kiplinger says apps approximate ranges by equal weighting [S21]. A search of `js/23-copy-test.js` and `js/29-leaderboard.js` found no SPY or benchmark comparison (not an exhaustive code review).
- User problem: a raw return invites a wrong conclusion. Users should see the same result next to SPY, starting from the filing date, with costs, and with the range assumption stated.
- Fit: reuse the Phase 4 method (filing-date start, 50 bps round trip, FDR control). Our current `insights.json` has no confirmed findings, so the honest message stays "mostly no edge after delay" if the data says so.
- Risks: must carry the simulated, not advice, and past-results labels (V13, V22). No new data source.

### R6. Portfolio-level digest from existing news reads
- Owner: `architect`
- Impact: medium. Effort: M.
- Evidence: Robinhood Portfolio Digests summarize what may affect a user's holdings, behind Gold at $5 a month, and are still a rolling release [S15]. Simply Wall St sends a weekly portfolio update email [S9]. Fiscal.ai and Perplexity sell AI answers with source links [S10, S11]. We already have per-ticker news reads with cites and a device-held "My reads" list (`docs/ARCHITECTURE.md`, News read agents).
- User problem: a list of per-stock reads still leaves the user to work out what matters across the whole portfolio this week.
- Why architect: it is a new capability that touches the news contract (a roll-up record, new validator rules, how holdings reach the builder without being stored).
- Risks: advice rules (a roll-up can sound like "what to do"), the cap of Groq calls, V1 number checks across many tickers, holdings only in memory per the data classification table. Robinhood requires a disclaimer that it is not research or a recommendation [S15].

### R7. Evaluate a read-only API or MCP for our derived data
- Owner: `architect`
- Impact: low. Effort: M.
- Evidence: Quiver sells API access and MCP tools [S2, S4], Unusual Whales offers an API, MCP server and agent skills [S5], Fiscal.ai sells API and MCP at custom pricing and ships a ChatGPT app [S10].
- User problem: power users and AI tools want to pull data in. For us this is optional.
- Why only evaluate: our daily files mix official records with FMP data, so licensing and rate-limit cost must be settled first. Scope to our own derived files (insights, strategies, news reads) if anything.
- Risks: data licensing (FMP terms), cost, abuse and prompt-injection from agents reading our text, new public surface for appsec. Do not start before the architect confirms the demand.

## Not recommended this month

- Auto-trading or copy orders into a broker (Autopilot model). Breaks the house rule that nothing places trades [S8].
- Real-time claims. Every guide says filings cannot be real time [S1, S21]. Keep "as filed" and the footer wording.
- Paid tiers. Not a competitive-intel call; noted only because all peers have free tiers with limits [S9, S10, S2].
